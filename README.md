# ADSolutions Digital Card

ADSolutions Digital Card is the standalone ADSolutions platform for premium digital business cards with Apple Wallet and Google Wallet integration.

## Current routes

- `/` — product landing page
- `/builder/` — interactive Card Builder
- `/card/andreas/` — Andreas Demetriou digital business card

## Wallet roadmap

Apple Wallet signing will be enabled once the ADSolutions Apple Developer Program enrollment is approved and the Pass Type ID certificate is available.

Google Wallet will use the same card-profile architecture through a Google Wallet Issuer account.

## Security

Never commit Apple signing certificates, private keys, certificate passwords, Google service-account credentials, or other secrets to this repository.
